# Top Label · sitio web

Propuesta de sitio para Top Label S.A. de C.V. (Querétaro): página de inicio y configurador 3D de etiquetas.

- `index.html` — página de inicio
- `configurador.html` — Top Label Studio (diseño 3D, cotización y pedido)
- `js/core.js` — datos de contacto (`TL_CONFIG`), catálogos, precios (`TL.quote`) y visor 3D

Para verlo en local: `python -m http.server 5173`

Los precios y datos de contacto son de ejemplo. Las marcas de productos mostradas pertenecen a sus respectivos dueños.
